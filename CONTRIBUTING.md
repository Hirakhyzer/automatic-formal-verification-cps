# Contributing

Contributions are welcome when they preserve the research and safety boundaries of the project.

Please:

1. Add tests for new set operations, reachability algorithms, parsers, or domain models.
2. State whether a method is sound/over-approximating, heuristic, or simulation-only.
3. Keep cyber scenarios abstract and bounded; do not add operational exploitation material.
4. Document units and assumptions for every CPS domain model.
5. Do not report synthetic benchmark numbers as measurements from real facilities or vehicles.
6. Prefer reproducible, seeded experiments and machine-readable results.
