# Security and safety scope

This repository is a **simulation and formal-methods research artifact**. It does not target live industrial, transportation, utility, robotic, battery, or railway infrastructure.

Cyber effects are represented only as bounded mathematical uncertainty or synthetic in-memory perturbations. The project intentionally excludes credentials, exploit payloads, vendor-specific attack procedures, real operational addresses, and instructions for compromising deployed CPS.

Formal results are conditional on the supplied mathematical model, initial set, uncertainty bounds, property, time horizon, and implemented method. A `VERIFIED_SAFE` result is **not** a deployment certification or a claim of real-world system safety.
