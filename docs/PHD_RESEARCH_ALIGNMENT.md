# PhD research alignment

This repository contributes a **formal-methods pillar** to a broader trustworthy cyber-physical systems program.

Existing work explores cross-domain anomaly reasoning, diagnosis, recovery, and federated trust. Reachability analysis adds a different kind of claim: under a defined mathematical model and bounded uncertainty, an unsafe set is unreachable over a finite horizon.

Potential dissertation contribution:

> A trustworthy digital-twin cyber-resilience framework that combines empirical anomaly diagnosis with sound reachable-set safety verification, using calibrated uncertainty to decide when a runtime digital twin is precise enough to support a formal safety envelope.

This should be evaluated as a methodological contribution, not as a claim that one reduced-order model certifies a deployed CPS.
