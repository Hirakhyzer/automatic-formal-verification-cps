# References and related software

The repository is an independent educational/research implementation. Useful external reference ecosystems include:

1. **CORA — COntinuous Reachability Analyzer.** A mature MATLAB toolbox for reachability analysis of continuous and hybrid systems and multiple set representations.  
   https://github.com/TUMcps/CORA

2. **JuliaReach / ReachabilityAnalysis.jl.** Set-propagation-based reachability for continuous and hybrid dynamical systems with uncertain initial states, parameters, and inputs.  
   https://github.com/JuliaReach/ReachabilityAnalysis.jl  
   https://juliareach.github.io/ReachabilityAnalysis.jl/stable/

3. **LazySets.jl.** Set representations and set computations used in the JuliaReach ecosystem.  
   https://github.com/JuliaReach/LazySets.jl

4. **NNV (Neural Network Verification).** Reachability-oriented verification research for neural networks and learning-enabled cyber-physical systems.  
   https://github.com/verivital/nnv

Any future paper based on this repository should cite the original algorithms actually implemented or compared, rather than citing only software home pages.
