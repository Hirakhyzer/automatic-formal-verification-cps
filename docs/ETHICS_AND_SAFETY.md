# Ethics and safety

The objective is safer CPS research through transparent modeling and verification.

The project must not be extended with operational instructions for attacking real CPS. Any cyber scenario should be expressed as a bounded mathematical perturbation, synthetic trace, or safe simulator-only condition.

Formal verification can create false confidence if assumptions are hidden. Therefore every report should make the model, horizon, uncertainty bounds, and method explicit. A safe result under an incomplete model is not evidence that the real system is safe.
